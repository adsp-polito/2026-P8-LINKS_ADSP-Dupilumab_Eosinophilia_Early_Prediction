*Applied Data Science Project — Politecnico di Torino, in collaboration with Fondazione LINKS*

## Overview

DEEP (Dupilumab Eosinophilia Early Prediction) is a project developed as part of the *Applied Data Science Project* course at Politecnico di Torino.

The project aims to develop a machine learning model to predict the risk of eosinophilia in patients with Chronic Rhinosinusitis with Nasal Polyps (CRSwNP) undergoing Dupilumab treatment.

Using baseline demographic and clinical features, the main objective is to formulate a binary classification task to predict whether a patient's blood eosinophil count will exceed 0.8 × 10³ cells/μL during treatment.

Additional analyses include exploring correlations between clinical features and investigating the time to eosinophilia onset.
